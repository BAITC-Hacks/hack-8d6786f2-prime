Сәт — подбор подрядчиков. Windows x64.

1. Распакуйте ВЕСЬ архив в обычную папку. Не запускайте EXE внутри ZIP.
2. Откройте Start.exe. Сайт откроется в браузере.
3. Оставляйте окно приложения открытым во время проверки. Ctrl+C останавливает сервер.

Python, Node.js и отдельный сервер SQL не нужны.
Порт по умолчанию: http://127.0.0.1:8765
Администратор: http://127.0.0.1:8765/#/admin

Данные сохраняются между запусками в %LOCALAPPDATA%\SatContractors.
Там находятся catalog.sqlite3 и файл настроек .env.
Код доступа к админ-панели создаётся при первом запуске в поле ADMIN_API_TOKEN файла .env.
Откройте .env Блокнотом и скопируйте значение после ADMIN_API_TOKEN= в панель.
Не передавайте свой .env вместе с приложением.

Без API-ключа работают поиск, SQL, анкеты, модерация и базовые объяснения.
Для живого ИИ заполните OPENAI_API_KEY в .env и перезапустите приложение. Нужен интернет.
Ключи разработчиков в архив не включены.

Проверка: Алматы, 14.11.2026, корпоратив, Ведущий, 1500000 тенге, русский, 6 часов.
Ожидаются три карточки из четырёх подходящих профилей исходного каталога.
Для отсутствия точного результата уменьшите бюджет до 600000: появятся альтернативы.
Отправленная анкета попадает в подбор только после одобрения администратором.
Календарь набора данных: 23.09.2026–31.12.2026.

Если порт занят: Start.exe --port 8766
Для отдельной тестовой базы: Start.exe --data-dir C:\Sat-Test
