# Независимые acceptance-проверки

Тесты обращаются к **реально запущенному HTTP API**. Они не импортируют backend,
не используют TestClient и не воспроизводят алгоритм подбора. Ожидаемые ID контрольных
сценариев зафиксированы для исходного CSV; общие инварианты проверяются по его полям.

## Запуск

Из корня репозитория после установки `backend/requirements-lock.txt` в `.venv`:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest qa/test_acceptance.py -q -s -p no:cacheprovider
```

По умолчанию сервер ожидается на `http://127.0.0.1:8000`. Тесты сами его не запускают.
Для другого экземпляра:

```sh
BASE_URL=http://127.0.0.1:18080 PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest qa/test_acceptance.py -q -s -p no:cacheprovider
```

`QA_CSV_PATH` — необязательный путь к CSV; по умолчанию `data/contractors.csv` относительно
репозитория, а не текущей папки. Версия сервера должна совпадать с SHA256 этого файла.
Набор рассчитан на исходные 66 профилей. При изменении данных требуется пересмотр
ожиданий, а не механическая замена ID до зелёного результата.

Сервер должен работать без настроенной AI-модели: fixture требует `ai_available=false`
до POST-запросов. Это ограничение данного fallback-набора, а не требование к продукту.
Не меняйте эту защиту ради массовых запросов к платному провайдеру. Тесты не читают `.env`.
Настройки окружения процесса pytest не меняют настройки уже работающего сервера.

Если нужен отдельный экземпляр без ключей, в отдельном терминале из корня:

```sh
PYTHON_DOTENV_DISABLED=1 OPENAI_API_KEY='' NVIDIA_API_KEY='' LLM_PROVIDER=openai LLM_TIMEOUT_SECONDS=6 PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 18080
```

## Покрытие и интерпретация

50 pytest-проверок: health/options; 7 контрольных сценариев; границы бюджета,
длительности и календаря; ошибочные и отсутствующие параметры; необязательные поля;
повторный порядок и preferences; календарь площадки в двух категориях; редкая категория;
фотографы, залы, ансамбли; выдача из двух; пометки подготовленных данных; время ответа.
Число тестов не равно числу HTTP-запросов: некоторые выполняют несколько запросов.

Во всех успешных рекомендациях проверяются структура, отсутствие дубликатов, лимит,
поля CSV, ограничения, evidence и fallback. Проверка цитат подтверждает происхождение,
но **не доказывает качество объяснения** и не проверяет каждый возможный выдуманный факт
в свободном тексте. Индивидуальность, 1–2 предложения и качество требуют ручного просмотра.
Повтор после перезапуска проверялся отдельно: см. `docs/launch-review.md`.

Существующий набор запускается отдельно:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHON_DOTENV_DISABLED=1 OPENAI_API_KEY='' NVIDIA_API_KEY='' .venv/bin/python -m pytest backend/tests -q -p no:cacheprovider
```

Прогон от 23.09.2026: 50 новых + 52 существующих проверки, подробности в
[матрице приёмки](../docs/acceptance.md). Нагрузочный тест и живая LLM не выполнялись.
