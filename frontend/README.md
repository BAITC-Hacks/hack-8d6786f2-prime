# Интерфейс подбора

React, TypeScript, Vite. Единственная страница — параметры мероприятия и результат. Пять обязательных полей, язык и длительность опциональны. Три исхода различаются текстом; базовые объяснения и подготовленные данные помечены. Альтернативы отделены от точных карточек и требуют повторного поиска.

Из этой папки:

```sh
npx --yes pnpm@11.19.0 install --frozen-lockfile
npx pnpm@11.19.0 dev
```

Vite работает на 5173 и проксирует `/api` на backend 8000. Для другого адреса задайте `BACKEND_URL`. Для обычного единого запуска следуйте [корневому README](../README.md).

Проверки: `pnpm test`, `pnpm build`; полный изолированный браузерный набор из корня: `python qa/run_e2e.py`. Тестовые фикстуры используются только тестами. Сайт всегда обращается к API; режима подстановки демонстрационных ответов нет.

Скриншоты и трассы проверок создаются в игнорируемых `test-results/` и `qa/artifacts/`. Их не требуется коммитить. Контракт: [api.md](../contracts/api.md).
