# Дизайн «сәт»

Референс создан до реализации интерфейса: `reference.html`, самостоятельный локальный HTML/CSS, без внешних шрифтов, платных ресурсов и генерации через сервис. Откройте файл в браузере. Это визуальное направление, а не реальные результаты подбора. Все три профиля вымышлены и обозначены.

Проверка возможностей 23.09.2026: среди доступных подключённых инструментов нет Figma/Canva. Проверенные [Figma REST file endpoints](https://developers.figma.com/docs/rest-api/file-endpoints/) предназначены для чтения и экспорта файлов. [Canva Autofill](https://www.canva.dev/docs/apps/rest-apis/reference/autofills/) требует Enterprise; ограниченный trial доступен платным планам при разработке. Подтверждённого бесплатного API для этой задачи в окружении нет. Использован разрешённый заданием локальный вариант; никаких покупок или аккаунтов не требовалось.

## Визуальное направление

- Тёплый фон `#f7f8f2`, белые карточки, основной тёмно-зелёный `#294c3d`, светлая зелень для объяснений.
- Заголовок Georgia, интерфейс Segoe UI / системный sans-serif. Не требуется загрузка шрифтов.
- Desktop: форма слева, три последовательные карточки справа; mobile: форма, затем результаты.
- Порядок внутри карточки: имя и цена → факты → серверное объяснение → раскрываемое описание.
- Инициалы вместо фото: API не содержит фотографий; интерфейс не приписывает подрядчикам чужие изображения.
- Видимый фокус, подписи каждого поля, семантическая форма и объявления состояний для скринридера.
- Название «сәт» используется как локальная дизайн-концепция проекта «Умный подбор подрядчиков».
