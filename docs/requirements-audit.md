# Аудит требований и расширения платформы

Источник обязательных требований — кейс «Умный подбор подрядчиков (#79-lite)», предоставленный командой. SQL, публичная анкета, модерация и административная панель добавлены по запросу капитана; исходное задание их не требует. Они не заменяют качество рекомендаций и объяснений.

## Приоритеты приемки

| Требование | Проверяемое поведение | Свидетельство |
| --- | --- | --- |
| Город, дата, формат, категория, бюджет; язык и длительность опциональны | Невалидные запросы отклоняются, все заданные ограничения применяются | Исходные тесты backend и независимые HTTP-проверки |
| Не более трех точных карточек | Каждая проходит все условия; занятый на исходную дату профиль отсутствует | Сверка независимым тестом с CSV |
| Конкретные объяснения | У трех карточек разные факты, цитаты проверяемы; качество текста проверяется дополнительно вручную | Автоматическая уникальность текста недостаточна для оценки качества |
| Неполная выдача объяснена | Показаны фактическое число и причины исключения | Тесты плотной и редкой категорий |
| Три исхода различимы | matched / no_category / no_match, осмысленный текст и UI | HTTP и браузерные сценарии |
| Стабильный порядок | Один запрос и один снимок данных дают один порядок | Повторный HTTP-запрос и перезапуск |
| Разные даты меняют выдачу | 14.11.2026: нет ведущего до 600000; 15.11: HK-88430 | Проверка по исходному календарю |
| Скорость около 10 секунд | Отдельно измерять реальный API и резервный режим | Тест без ключа не подтверждает скорость OpenAI |
| Происхождение данных видно | synthetic, city_imputed, price_imputed сохранены и показаны | HTTP и UI |
| Воспроизводимость | Установка, seed, SQL, переменные среды, запуск и демонстрационные запросы документированы | Требует финальной проверки README после интеграции |

## Условия, которые нельзя нарушить расширением

- Альтернативы отделены от точных совпадений. Для занятых специалистов показывается действительно свободная дата и явные изменения параметров. Кнопка заполняет форму, после чего пользователь запускает новый поиск.
- Исходные город, категория и формат не меняются. Не обещается существование альтернативы, если подходящего профиля нет даже после допустимых изменений.
- Pending и rejected не участвуют в поиске. Только approved входит в публичный снимок каталога. Контактный email доступен в панели, но отсутствует в рекомендациях и options.
- Администратор не видит пароли: пароли подрядчиков вообще не собираются. Токен администратора проверяется сервером, не попадает в URL, localStorage, ответы API или журналы анкеты.
- Удаление подтверждается именем анкеты, выполняется транзакционно и не отменяется повторным импортом seed при рестарте.
- SQLite хранит состояние между процессами. CSV остается воспроизводимым начальным набором, а не источником, который заново затирает модерацию.
- Конкурентное решение на устаревшей ревизии возвращает 409, а не молча перезаписывает чужую модерацию.

## Ограничения оценки

Оценку жюри по стобалльной шкале нельзя вывести из числа тестов. Ниже будут зафиксированы только реально выполненные проверки и оставшиеся ограничения. Статус нового расширения до завершения интеграции — «на приемке».

Живое качество LLM требует просмотра минимум трех объяснений: техническая проверка фактов не доказывает полезность и естественность текста. Текущий календарь намеренно ограничен 23.09–31.12.2026 исходными данными. Публичная анкета без учетных записей и отдельный административный токен соответствуют согласованному сценарию, но не дают личного кабинета для самостоятельного редактирования подрядчиком.
