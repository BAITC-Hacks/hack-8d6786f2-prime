# Передача расширения участникам команды

Статус: черновик для распределённой доработки, не принят в main. Исходный принятый main — e1ec605. После уточнения капитана внутренние агенты остановлены; работу продолжают два других участника команды по промптам в `docs/team-prompts/`.

Первый агент отвечает за backend/SQL/API и слияние; участник 2 — frontend (кроме браузерных тестов); участник 3 — QA, браузерные тесты и аудит. Стартовая ветка всех новых задач — `origin/feat/catalog-platform`, собственные ветки — `feat/provider-admin-ui` и `test/platform-acceptance`.

- 52 исходных backend-теста прошли после перехода на SQLite.
- Отдельный тест удаления профиля во время подготовки объяснения прошёл.
- Внутренний QA сообщил 73 прошедших независимых HTTP-проверки на временной БД.
- Четыре новых сквозных сценария были пройдены на промежуточном UI. Найден пограничный контраст подписи, исправление внесено, но итоговый полный браузерный прогон прерван при передаче.

## Открытые пункты

- Синхронизировать бизнес-валидацию max_hours: null обозначает неприменимость присутствия, а не отсутствие лимита. Запрет для новых анкет ведущего/фотографа и смешанных категорий ещё не реализован; согласовать исключения для флориста, декоратора, подарков.
- Пройти новые и исходные браузерные тесты совместно. Черновик скрывает старую кнопку подсказки даты при наличии alternatives; существующий E2E, который находит её по имени, требует согласования с новым пользовательским сценарием.
- Повторить визуальную проверку и доступность новых страниц после окончательных изменений.
- Проверить запуск с нуля, завершение дочерних процессов тестового runner на Windows и итоговый README.
- Выполнить один живой OpenAI-запрос на итоговой версии. Ключи в рабочих копиях не передаются через Git; тестовые серверы работают без ключей и с временными БД.
