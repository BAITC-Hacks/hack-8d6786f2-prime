## Перепроверка известных дефектов

- **QA-Q01 — CLOSED для контрольных примеров.** На 23.09 и 25.12 запрос Алматы / свадьба / Лайв-бэнд / 10000000 / language=null / duration_hours=null возвращает разные факты услуги. У HK-23752 перечислены два вокалиста, вокалистка, труба, саксофон и тромбон; у HK-83709 — четыре вокалиста, струнный квартет и перкуссионист, с остальным составом из CSV. Ручное чтение подтверждает содержательное различие после удаления названий, а не только неравенство строк. Штатный тест также проверяет эти факты в альтернативных карточках.
- **QA-Q02 — CLOSED для HK-42352.** Запрос Алматы / 23.09 / свадьба / Ведущий / 10000000 / казахский / 10 ч возвращает завершённый дословный факт «Опыт ведения свадеб 13 лет». Обрыв на «чтобы этот» больше не воспроизводится. Совпадение с CSV проверено.
- **QA-Q03 — CLOSED для двух флористов.** Запросы на 14.11 для Алматы и Астаны, свадьба / Флорист / 300000 / language=null / duration_hours=null дают корректное «Подходит 1 профиль». Для Астаны — «в каталоге всего 1 профиль»; для Алматы указано число исключённых и причина занятости.
- **QA-T01 — CLOSED.** Ранее падавший штатный сценарий `real API options, ranked matches, fallback, desktop and mobile` прошёл; весь актуальный браузерный набор — 22 passed. Исходники тестов взяты из caf7772 без локальных правок.
- **QA-Q04 — сохраняет статус CLOSED.** Браузерная проверка альтернатив и явного повторного поиска прошла. Точная выдача и предложения изменения условий остаются разделены.

## Окружение и воспроизведение

Ubuntu 26.04; Python 3.14.4; Node 22.22.1; зависимости по неизменённым backend/requirements-lock.txt и frontend/pnpm-lock.yaml. Для быстрого прогона повторно использованы установленные зависимости после проверки совпадения lock-файлов. Чистая установка заново не выполнялась. Браузер — установленный Chromium для Playwright; использован отдельный локальный кеш через PLAYWRIGHT_BROWSERS_PATH.

Из корня проверенной версии, с установленными зависимостями:

```sh
python -m pytest backend/tests qa -q -p no:cacheprovider
python qa/run_e2e.py
```

Из frontend:

```sh
pnpm test
pnpm build
```

Дополнительные HTTP-запросы соответствуют JSON и изменениям из таблиц выше; они выполнены через существующий isolated_server с временной SQLite, отдельным процессом и случайным локальным портом. Загрузка .env и ключи AI отключены. Рабочий сервер команды и его база не использовались.

## Ограничения и дальнейшие действия

- Живой LLM не вызывался. В этом прогоне подтверждены fallback и штатные тесты с имитацией провайдера. Заявленные в документации команды живые вызовы отдельно не перепроверялись.
- Нагрузочные и расширенные security-проверки, Python 3.12, Windows/EXE и доступ жюри заново не проверялись. Прежний риск задержек при высокой параллельности этим быстрым прогоном не закрывается.
- Pytest выдал одно предупреждение Starlette/httpx о deprecated-интеграции TestClient; тесты завершились успешно. Зависимости в рамках QA не менялись.
- Закрытие конкретных дефектов не гарантирует качество всех возможных описаний каталога. После следующих изменений требуется новый прогон с новым SHA.

QA-коммит добавляет только этот отчёт. Приложение, данные и существующие тесты в ходе проверки не редактировались.
