# Исправления архитектурного аудита

Отчёт организовал замечания по версии `146b974`. Исправления законченных цитат и различий лайв-бэндов уже вошли в `caf7772`; текущая работа продолжает эту версию, сохраняя исходные 66 профилей и порядок подбора.

| Пункт отчёта | Изменение и способ проверки |
| --- | --- |
| 1. Различимость группы | После LLM сравниваются признаки всей группы с fallback. При потере фактов восстанавливаются цитаты; недостаток отличий явно сообщается. Регрессии на бэндах и допустимой, но менее конкретной цитате площадки |
| 2. Приёмка и CI | Актуальные локаторы, общий помощник формы, полный браузерный набор. GitHub Actions запускает все проверки без API-ключа и прикрепляет артефакты к SHA |
| 3. Измерение качества | 28 фиксированных запросов, 17 категорий, все исходы, сентябрь/декабрь, разные даты, площадки и null-длительность. Один набор для fallback/живого AI; отдельные времена новых запросов и кеша |
| 4. Причины смены даты | `assessments` с id, причиной и рангом; сравнение соседних результатов. Сценарий 14 → 15 ноября различает занятость HK-29829, доступность HK-88430 и выход HK-27222 за границу тройки |
| 5. Обрывы цитат | Сохранён общий выбор законченных фрагментов из `caf7772`; оба варианта свадебного запроса входят в приёмку |
| 6. Одновременные вызовы | 10 одинаковых запросов → один внешний вызов. Ограниченные слоты/очередь, общий таймаут, один HTTP-клиент, пауза после сбоев, квоты вызовов, диагностика и закрытие клиента |
| 7. Контракты | Максимум три карточки, статусы с discriminator, типизированные changes, согласованные счётчики и причины. Генерация типов OpenAPI и проверка 28 реальных JSON-ответов Zod-схемой |
| 8. Чтение каталога | Общий снимок в памяти; явный атомарный refresh и документированный перезапуск/новая папка данных для обновления. Повторные запросы не читают SQL и не пересчитывают хеш |
| 9. Интерфейс и выбор | Форма, карточка, результаты, альтернативы и управление запросом разделены. Политика «цена, затем id» объяснена рядом с результатами |

README содержит все 11 разделов из промпта организаторов, собственный API-ключ проверяющего, безопасный placeholder и команды проверки. Ненастроенный ключ сохраняет рабочий fallback.

## Обоснованные границы

Эвристические признаки не доказывают семантическое превосходство. На этом небольшом каталоге fallback часто выбирает те же полезные факты, что и модель; качество исходников остаётся ограничением. Нельзя заявлять, что AI улучшает все карточки или ранжирует подрядчиков.

Кеш, квоты и снимок рассчитаны на один процесс. Календарное окно в метаданных, синхронизация нескольких процессов, глобальный денежный бюджет, SQL-фильтрация большого набора и смысловой рейтинг — дальнейшее развитие при измеренной потребности. Административный API и лишние продуктовые функции не добавлены.

Публичного хостинга и готового GitHub Release в этой работе нет. Жюри может повторить запуск на своём компьютере; доступ к private-репозиторию выдаёт команда. Фактические результаты и SHA: [verification.md](verification.md).
