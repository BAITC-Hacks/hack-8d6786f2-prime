# Агент 1 — моя зона работы с капитаном

Я отвечаю за backend, SQL, алгоритм рекомендаций, API-контракт, проверку общих изменений и последующее слияние после одобрения капитана. Два других участника работают самостоятельно по отдельным промптам; внутренних агентов больше не запускаю.

Уже подготовлено отдельно от main:

- SQLite-хранилище, одноразовый импорт CSV, устойчивость данных после перезапуска;
- публичная подача анкет, серверная валидация, статусы модерации;
- авторизованные просмотр/добавление/одобрение/отклонение/удаление;
- транзакции, проверка revision, скрытие контактов и секретов из публичного API;
- отдельные альтернативы с объяснёнными изменениями условий;
- защита от возврата удалённого профиля из длительного LLM-запроса;
- рабочий контракт `contracts/platform-v2.md`.

Остаётся за мной:

1. Закрыть бизнес-валидацию max_hours: пустое значение не должно превращать услугу присутствия в неограниченную; согласовать правило с интерфейсом и QA.
2. Обработать воспроизводимые backend-замечания третьего участника.
3. Проверить SQL-миграцию/запуск, настройки административного доступа и живой OpenAI на итоговом коде.
4. Принять коммиты UI и QA, проверить совместимость, повторить только необходимые общие проверки.
5. Подготовить конкретный результат для апрува капитана и затем слить расширение в main. Текущий принятый main и локальный работающий сайт остаются базовой версией до новой приёмки.

Ветка передачи черновика: `feat/catalog-platform`. Черновой frontend и QA сохранены, чтобы участники могли довести работу вместо повторного написания.
