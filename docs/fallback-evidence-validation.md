# Проверка объяснения HK-19103

Замечание QA от 23.09.2026 подтверждено: fallback выбирал длинный рекламный призыв «…свяжитесь с нами». Цитата была из исходного описания, но не объясняла особенность ансамбля.

В выборе цитаты понижен приоритет призывов связаться/заказать/забронировать и общих обещаний выступить на мероприятии. Правило применяется ко всем профилям, без исключений по ID. При наличии только рекламного текста остаётся исходная цитата: новые характеристики не придумываются. Это эвристика для русскоязычного fallback, а не гарантия распознавания любой рекламы. Алгоритм LLM и порядок подрядчиков не менялись.

## Повторная проверка для QA

В тестовом API без ключа провайдера выполнить `POST /api/recommend`:

```json
{
  "city": "Алматы",
  "date": "2026-11-14",
  "event_type": "той",
  "category": "Национальный ансамбль",
  "budget_kzt": 400000,
  "duration_hours": 2,
  "language": "казахский"
}
```

Ожидается `meta.explanation_mode = "fallback"`. Для HK-19103 цитата в объяснении и `evidence`:

> Творческий коллектив Sakura Dala — духовная, энергичная команда джигитов

Это наиболее содержательный из доступных фрагментов данного описания. Количество артистов, инструменты и репертуар в источнике не указаны, поэтому они не добавляются в объяснение.

## Результаты

- `pytest backend/tests`: **90 passed**. Включены отдельный API-сценарий HK-19103, пять вариантов рекламного текста с совпадением пожеланий и проверка описания без содержательной альтернативы.
- Сравнены старые и новые цитаты на 193 сочетаниях профилей и заявленных форматов из текущего CSV, без дополнительных пожеланий. Изменился только HK-19103 — для тоя, свадьбы и юбилея; все остальные выбранные фрагменты совпали. Все новые цитаты являются точными подстроками источника. Это проверка выбора фрагментов, а не 193 независимых проверки наличия кандидатов.
