# Backend подбора

Python/FastAPI. Основной запуск всего приложения описан в [README](../README.md). Для разработки отдельного API:

```sh
python -m pip install -r backend/requirements-lock.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Настройки в локальном `backend/.env`, переменные процесса имеют приоритет. Шаблон — `.env.example`.

| Переменная | Назначение |
| --- | --- |
| LLM_PROVIDER | openai или nvidia |
| OPENAI_API_KEY / OPENAI_MODEL | Ключ и модель; по умолчанию gpt-4o-mini |
| NVIDIA_API_KEY / NVIDIA_MODEL | Ключ и модель NVIDIA |
| LLM_TIMEOUT_SECONDS | Таймаут вызова вместе с очередью: 6 с по умолчанию, максимум 8 с |
| LLM_MAX_CONCURRENCY | До 4 внешних вызовов одновременно по умолчанию; от 1 до 16 |
| LLM_CALLS_PER_MINUTE | До 30 новых внешних вызовов за скользящие 60 секунд |
| LLM_CALLS_PER_SESSION | До 500 новых внешних вызовов за время работы процесса |
| DATABASE_PATH | SQLite; по умолчанию data/catalog.sqlite3 |
| CONTRACTORS_CSV | Источник первого импорта; по умолчанию data/contractors.csv |
| SAT_DATA_DIR | Отдельная папка настроек и состояния |
| SAT_FRONTEND_DIR | Необязательный путь к собранному frontend |

Без ключа используется fallback. Проверка живого провайдера: `python -m backend.check_llm`. `ai_available` не является проверкой доступности внешнего API. Для тестов задавайте временную базу, `PYTHON_DOTENV_DISABLED=1` и пустые ключи.

В `.env.example` оставлен `PASTE_YOUR_OPENAI_API_KEY_HERE`: замените собственным ключом. Незаменённый placeholder считается отсутствием ключа и не вызывает платный API.

Один HTTPX-клиент живёт до завершения FastAPI lifespan. Одинаковые запросы делят одну задачу; отмена одного потребителя её не отменяет. Число выполняющихся и ожидающих задач ограничено четырьмя на слот, излишек сразу получает fallback. После трёх ошибок срабатывает пауза 30 секунд. Кеш и лимиты действуют в пределах одного процесса. `meta.ai` сообщает кеш, объединение запросов, восстановление фактов и причину fallback. Тела ошибок провайдера и ключи не логируются.

SQLite импортирует CSV один раз. Повторный запуск не перезаписывает готовую базу и работает без исходного CSV. HTTP-интерфейс не меняет каталог. Версия данных — SHA256 публичного снимка. Старые базы версии схемы 1 читаются без удаления их таблиц или частных полей; в публичный ответ попадают только поля карточки.

[API](../contracts/api.md) · [Архитектура](../docs/architecture.md) · [Ограничения](../docs/known-issues.md).

Снимок читается и хешируется при старте, затем используется всеми запросами. Внутренний `Store.refresh()` строит новый снимок в согласованной транзакции и заменяет ссылку только после успешного чтения. Для ручного обновления базы остановите сервер и запустите заново. Для нового CSV используйте новую папку `SAT_DATA_DIR`, сохранив прежнюю базу. Автоматического обновления календаря нет.
